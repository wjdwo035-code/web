01. 시각 방향

  • 밝고 절제된 B2B 기업 홈페이지 분위기를 유지합니다.
  • 넓은 여백으로 메시지와 이미지의 우선순위를 분명하게 표현합니다.
  • 짙은 차콜 텍스트와 오렌지 포인트로 CTA와 순서를 강조합니다.
  • 과도한 그래디언트, 숫자 카운터, 자동 재생 애니메이션, 장식용 아이콘 남용은 사용하지 않습니다.

디자인 토큰

본문 배경 / #FFFFFF
보조 배경 / #F6F7F9
본문 텍스트 / #25282D
포인트 / #FF6400

02. 레이아웃 원칙

  1. 헤더: 데스크톱 메뉴와 상담 CTA를 사용하며, 모바일에서 햄버거 메뉴로 전환합니다.
  2. 히어로: 큰 메시지·CTA·이미지를 배치하고, 데스크톱 2열과 모바일 1열을 유지합니다.
  3. 정보 섹션: 핵심 제목과 짧은 설명 뒤에 카드·목록·타임라인을 배치합니다.
  4. 서비스 카드: 동일한 이미지 비율, 흰색 카드, 얇은 경계선, 20px 모서리로 통일합니다.
  5. 문의: 안내와 양식을 하나의 그룹으로 구성하고, 실제 전송 경로가 없으면 이를 명확히 표시합니다.

04. 수정 요청 작성·처리 기준

수정 범위를 분명히 하여 의도하지 않은 디자인·기능 변경을 줄입니다.

항목기록 내용예시
수정 대상문제가 발생한 메뉴, 버튼, 이미지, 문구 또는 레이아웃모바일 히어로 제목
발생 위치페이지 섹션과 화면 폭 또는 기기메인 화면, 390px
현재 문제관찰 가능한 현상제목이 3줄로 표시됨
원하는 변경크기, 위치, 동작 방식 등 기대 결과2줄 이내가 되도록 글자 크기와 줄 간격 조정
유지 조건수정하지 않아야 하는 범위PC 화면의 레이아웃과 기존 색상 유지

수정 우선순위

  1. 페이지가 열리지 않거나 리소스를 불러오지 못하는 실행 오류
  2. 메뉴, 버튼, 링크, 양식 등 상호작용 오류
  3. 글자·이미지 잘림, 콘텐츠 겹침, 가로 스크롤 같은 화면 오류
  4. 정렬, 여백, 크기 등 디자인 오류
  5. 색상, 표현, 전환 효과 등 세부 개선

처리 원칙

  • 변경 대상 외의 기존 콘텐츠·색상·레이아웃은 유지합니다.
  • 수정이 다른 화면 폭과 섹션의 정렬·동작에 미치는 영향을 함께 확인합니다.
  • 반복 오류는 문제 화면의 캡처, 사용 브라우저, 화면 크기를 함께 기록합니다.
  • 수정 후 데스크톱 1440px, 태블릿 768px, 모바일 390px에서 재검증합니다.

요청 예시

모바일 화면에서 메인 제목이 세 줄로 표시됩니다. 390px 기준으로 두 줄 이내가 되도록 글자 크기와 줄 간격을 조정해 주세요. PC 화면의 레이아웃과 기존 색상은 변경하지 않습니다.
